## 🚀 How to Upload via GitHub (GitHub හරහා Upload කරන ආකාරය):
1. ඔබගේ GitHub Repository එකට යන්න.
2. `public/albums/` folder එකට ගොස් ඔබට අවශ්‍ය Album folder එක (උදා: `01-traditional-sri-lankan`) විවෘත කරන්න.
3. ඉහළ දකුණු කෙළවරේ ඇති **Add file** -> **Upload files** click කරන්න.
4. ඔබ සකස් කරගත් `photo-01.jpg` සිට `photo-48.jpg` දක්වා ඡායාරූප 48 Drag & Drop කරන්න (නැතහොත් Choose your files මඟින් තෝරන්න).
5. පිටුවේ පහළ ඇති **Commit changes** button එක click කරන්න.

එපමණයි! ඔබ ඡායාරූප upload කළ විගස වෙබ් අඩවිය තුළ එම Album එකේ ඡායාරූප 48 සහ Spreads 24 ස්වයංක්‍රීයව දිස්වේ.
